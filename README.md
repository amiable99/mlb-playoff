# MLB 포스트시즌 대진표

MLB 포스트시즌 대진을 현재 순위 기준으로 그려서 보여주는 사이트. 순위나 매직넘버가 아니라
와일드카드부터 월드시리즈까지 실제로 만날 수 있는 상대와 상대전적, 일정에 집중한다.

## 📁 파일 구조

```
mlb_playoff/
├── server.py     # 서버 (요청 처리, 30분 캐시)
├── bracket.py    # MLB Stats API에서 데이터 가져오고 대진/로스터 계산
├── pages.py      # 서버 렌더링 HTML 페이지
├── teams.py      # 팀 정보(한글 이름, 색상), 한국인 선수 명단
├── static/       # CSS
├── ads.txt       # 애드센스
└── privacy.html  # 개인정보처리방침
```

## 🎯 핵심 기능

- **대진표(메인)**: 지구 우승 3팀 + 와일드카드 3팀으로 리그별 1~6시드를 정하고, 와일드카드
  시리즈 확정 대진과 디비전시리즈에서 만날 수 있는 상대를 상대전적과 함께 보여준다.
- **토너먼트**: 와일드카드부터 월드시리즈까지 전체 대진을 한 화면에, 아직 정해지지 않은
  라운드는 빈 칸(TBD)으로 표시.
- **팀 페이지**: 팀별로 만날 수 있는 상대, 상대전적, 전체 로스터.
- **한국인 선수**: 포스트시즌에 오른 팀 중 한국 출신 선수가 있는 팀을 모아서 보여준다.
- **가이드**: 라운드별 경기 방식(몇 전 몇 선승제, 홈구장 배정 규칙) 설명.

## 🔄 데이터 갱신

MLB Stats API(`statsapi.mlb.com`)에서 순위·일정·로스터를 가져와 30분 캐시로 재사용한다.
포스트시즌 26인 로스터는 각 팀의 라운드 첫 경기가 실제로 시작되면(경기 상태 Live/Final)
박스스코어를 통해 자동으로 확정 로스터로 전환된다 - 그 전까지는 40인 로스터 후보를 보여준다.

## 🚀 실행

```bash
pip install -r requirements.txt
PORT=8000 python3 server.py
```

`SITE_URL` 환경변수로 배포된 실제 주소를 지정하면 sitemap/canonical URL에 반영된다(생략하면
요청 Host 헤더로 자동 추론).
